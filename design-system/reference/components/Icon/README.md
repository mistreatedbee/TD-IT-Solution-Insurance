The app and website icon set: Lucide line icons on a 24px grid with a 1.75px stroke, round caps and joins, drawn in `currentColor`.

**You provide:** an icon name from the preview, a size (16, 20 or 24px), and the colour through the parent's `color`. Use `lucide-react` on the web and `lucide-react-native` in the app, both with `strokeWidth={1.75}`.

**Rules**
- Never mix in a second icon style, filled icons or emoji.
- Icons that carry meaning are at least 3:1 against their ground and always come with a word.
- Asset types use `laptop`, `car`, `smartphone`, `tv`; statuses use `shield-check`, `map-pin`, `clock`, `triangle-alert`, `circle-check`.
- Lucide is the icon set the website already uses. It is an open-source icon set, not a custom TD IT Solution drawing.
