Three repeating patterns in a light and a dark file each, drawn as seamless tiles. Light files use `brand-navy` lines at low opacity for the Day theme; dark files use white lines at low opacity for the Night theme.

- `pattern-chevron-*.svg`: 80px tile, nested chevrons from the logo.
- `pattern-rings-*.svg`: 200px tile, concentric location rings with a centre dot.
- `pattern-dots-*.svg`: 24px tile, a quiet dot grid.

Repeat them with `background-image` at the tile size above (`background-size: 80px 80px`, `200px 200px`, `24px 24px`). Use one pattern per screen. The ink is baked into each file; pick the file that matches the theme.
