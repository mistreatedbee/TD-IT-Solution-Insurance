The app icon set for iOS and Android, all built from the mark on a navy gradient (`brand-navy` to a deeper navy, with a soft `brand-blue` glow behind the mark).

- `app-icon.svg`: the editable source at 1024px.
- `app-icon-ios-1024.png`: full-bleed square, no transparency; iOS rounds the corners itself.
- `app-icon-android-foreground-1024.png` and `app-icon-android-background-1024.png`: the adaptive icon layers; the mark sits inside the central 66% safe zone.
- `app-icon-android-monochrome-1024.png`: white mark on transparent for Android themed icons. Its ink is white.
- `notification-icon-96.png`: white mark on transparent for the Android notification bar. Its ink is white; set the notification colour to `brand-orange`.

Never add text, a border or a shadow to the icon.
