The launch image: the mark centred on the Night backdrop with faint location rings and chevron lines. `splash-1284x2778.png` is for the operating system's launch screen (resize mode cover, background `#0B1622`); `splash.svg` is the editable source.

The animated version for the first seconds in the app is the `LoadingScreen` component; it starts from this same still, so the hand-off from launch image to animation is seamless.
