The company mark in five forms. `logo-full.png` is the supplied master lockup with the wordmark: use it on white or very light grounds at 120px wide or more, never redraw or recolour it.

- `logo-mark.svg`: the four chevrons, wordmark gap closed, in the brand colours (`brand-orange`, `brand-blue`). Use on light grounds.
- `logo-mark-on-dark.svg`: same mark with `brand-blue-bright` for the blue, for navy and Night grounds.
- `logo-mark-white.svg`: single ink, white (`#FFFFFF`). Use on photos or one-colour grounds.
- `logo-mark-navy.svg`: single ink, `brand-navy` (`#2C3E52`). Use on light grounds where colour is not allowed.
- `favicon.svg`: the mark on a rounded navy tile, for browser tabs.

The SVG marks are vector traces of the supplied logo's chevrons, so they match it to within a pixel. These files are shown through an image tag, so the single-ink files carry their ink in the file and cannot inherit text colour.
