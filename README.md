# TD-IT-Solution-Insurance

Enterprise **Insurance Asset Protection & Recovery Platform**. Customers subscribe to monthly plans and register valuable assets — vehicles, laptops, smartphones, tablets, TVs, desktop computers, and other business equipment. Registered assets can carry GPS tracking hardware; the platform ingests location data to help locate and recover lost or stolen assets, coordinating with security-company partners for field recovery.

Platform surfaces: Customer Mobile App, Admin Dashboard, Security Company Dashboard, Backend API, GPS Integration Layer, Payment System, Notification Services, Reporting & Analytics, Authentication System, Customer Support Portal.

## Project governance

This project runs under a full engineering organization — org chart, ownership matrix, feature lifecycle, and standards — documented in [`docs/organization/`](docs/organization/README.md). Start there before contributing.

## Current status

Phase 0 — foundation. The repository currently contains the design-system component library (below) and the engineering governance set. No backend, mobile app, database, or infrastructure exist yet — see the [roadmap](docs/organization/08-roadmap.md) for what's next.

## Stack

- **Web** (marketing site, Admin Dashboard, Security Company Dashboard): React 18 + Vite + TypeScript + Tailwind CSS
- **Mobile** (Customer App): Expo (React Native) + TypeScript — planned
- **Backend API**: Node.js + TypeScript — planned
- **Database**: MongoDB — planned

Full rationale: [ADR-0001](docs/organization/adr/0001-baseline-architecture.md).
