# `docs/organization/correspondence/`

Drafts of communications **to parties outside this engineering organisation** — the Client
(TD IT Solution (Pty) Ltd), vendors, and (if ever required) the Information Regulator.

**Rules for this directory:**

1. **Nothing here has been sent.** Every file is a draft prepared for a human with an actual
   channel to the recipient. No agent in this organisation has a channel to the Client, and none
   may represent that a document here was delivered.
2. **Filenames start with `DRAFT-`** until the owner confirms dispatch. On dispatch, the file is
   renamed `SENT-<date>-...` and a dispatch record (date, sender, recipient, channel, and any
   changes made before sending) is added at the top. A file that is still `DRAFT-` is, for every
   other document in this repo, **evidence that the communication has not happened.**
3. **No personal information, banking details, or contract text beyond what is already recorded
   in `docs/organization/`** — per `contract-tdit-2026-09-scope-summary.md`'s own standing rule.
4. Drafts of legal or notification significance carry a **pre-send checklist** of facts that must
   be verified by a named role before dispatch. Do not send past an unticked box.
